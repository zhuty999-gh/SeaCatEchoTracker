# 海毛虫 Echo Tracker

[English](README.md) | 简体中文

一个在《魔兽世界》**12.1（Midnight）**下仍然可用的恢复系唤魔人 Echo（回响）追踪插件。

本插件 fork 自 **Lazoro 的 EchoTracker**（MIT 协议）。界面基本沿用原作，但追踪机制被完全重写——因为原来的做法在 12.1 已经彻底失效。

## 为什么要 fork

12.1 之后，只要战斗、boss 战、大秘境或 PvP 限制生效，光环数据就会变成 **secret（保密值）**。官方 API 说明原文：所有 UnitAura 系列接口对插件而言「要么返回完全 secret 的值，要么返回 nil」，并且「AuraData 结构现在始终是完全 secret 的」。

原插件的做法是每 0.1 秒扫描全团、读取每个 Echo 的 `expirationTime`。在 12.1 下这条路会分两个阶段失败：

| 阶段 | 现象 |
| --- | --- |
| 直接读 secret 值 | 带着 Echo 进战斗后每 0.1 秒报一次 Lua 错误，必须 `/reload` |
| 加了防御性判断 | 不报错了，但图标彻底消失——光环为 secret 时按名称查询直接返回 nil |

没有别的光环接口能绕过它，这本身就是该限制的设计意图。

## 那它是怎么工作的

Echo 的任何信息都**不再从光环读取**，而是**根据你自己的施法序列推算**出来。这是合法且明文的：施法信息只在被查询单位不是玩家或其宠物时才会保密。

```
Echo / 时空异常（Temporal Anomaly）  →  压入一个到期时间
消耗类治疗法术                        →  一次性清空全部
青翠绽放（Emerald Blossom）           →  存下一层额外目标
```

Echo 的真实持续时间在**战斗外自动校准**（此时光环仍可读）并缓存下来。因此天赋 376240（每点 +15%）会被自动识别，不需要硬编码。

完整设计、法术表，以及试过并被否决的方案记录，见 [DESIGN.md](DESIGN.md)。

## 精度说明

这一点值得说清楚，因为两个数字的**误差方向相反**：

**倒计时是准确的，且误差一致偏保守。** 所有已知误差来源都只会让 Echo 看起来比实际更早过期，而这对「我该不该续 Echo」的判断而言正好是安全的一侧。

**计数是估算值，且误差偏高**，所以默认在团队副本外隐藏。时空异常最多给 5 个盟友上 Echo，但不会告诉插件是谁；之后再对其中某人施放 Echo，实际上是刷新，却会被算成新增一个。20 人团里按固定 5 计算是站得住的；5 人小队里球经常碰不到 5 个人，所以需要你自己在设置里勾选「在团队副本外也显示计数」。

注意**大秘境的副本类型是 `party` 而非 `raid`**，因此默认设置下大秘境里也看不到计数。

## 命令

| 命令 | 作用 |
| --- | --- |
| `/sce` | 打开/关闭设置面板 |
| `/sce spells` | 打印法术表及其实际名称，用于核对 ID |
| `/sce show` / `/sce hide` | 切换「始终显示」 |
| `/sce unlock` / `/sce lock` | 解锁/锁定，用于移动位置 |
| `/sce reset` | 恢复默认设置（保留已校准的持续时间） |

`/seacatecho` 和 `/et` 是等价别名，后者是为了照顾原插件的肌肉记忆。

建议每次职业补丁后跑一次 `/sce spells`：它会把配置里每个法术 ID 解析成当前的实际名称，法术一旦改号就能立刻看出来，而不是让追踪悄无声息地失效。

## 安装

把 `SeaCatEchoTracker` 文件夹放进 `World of Warcraft\_retail_\Interface\AddOns\`。

### 从原版 EchoTracker 迁移

全局变量和 SavedVariables 都做了改名，所以两个插件可以同时安装而不会抢设置。代价是一般情况下旧布局不会自动继承——WoW 的保存变量是按插件**文件夹**存的：你原来的设置在 `SavedVariables\EchoTracker.lua`，而本插件读的是 `SavedVariables\SeaCatEchoTracker.lua`。

两种保留旧设置的办法：

- **让两个插件同时启用着进一次游戏。** 原插件仍安装并启用时，它的 `EchoTrackerDB` 处于可见范围内，本插件会在首次加载时导入。之后再禁用或删除原插件即可。
- **手动复制文件。** 关闭游戏，把 `WTF\Account\<账号>\SavedVariables\EchoTracker.lua` 复制成同目录下的 `SeaCatEchoTracker.lua`，并把文件里的 `EchoTrackerDB` 改名为 `SeaCatEchoTrackerDB`。

从头开始配也完全没问题——设置项本来就不多。
